# C++ Module 04 — École 42

Projet développé en **C++98** dans le cadre du cursus de l'école 42.

Ce module approfondit les concepts de la **programmation orientée objet**, notamment le polymorphisme, les fonctions virtuelles, les classes abstraites et les interfaces.

## Exercices

- **ex00 — Polymorphism :** implémentation d'une hiérarchie de classes `Animal`, `Dog` et `Cat` pour comprendre le polymorphisme et les méthodes virtuelles.
- **ex01 — I don't want to set the world on fire :** gestion de ressources dynamiques avec une classe `Brain`, introduction à la copie profonde (*deep copy*).
- **ex02 — Abstract class :** transformation de la classe `Animal` en classe abstraite à l'aide d'une fonction virtuelle pure.
- **ex03 — Interface & recap :** implémentation d'interfaces avec `ICharacter` et `IMateriaSource`, manipulation d'objets `AMateria` et gestion de leur cycle de vie.

## Compétences mises en œuvre

- Programmation en C++98
- Héritage et polymorphisme
- Fonctions virtuelles et destructeurs virtuels
- Classes abstraites et interfaces
- Allocation dynamique et gestion de la mémoire
- Copie profonde et indépendance des objets
- Manipulation de pointeurs vers des classes de base
